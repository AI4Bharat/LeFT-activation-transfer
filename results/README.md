# Results

```
results/
  tables/   the aggregated numbers behind the tables of the manuscript (tracked)
  logs/     the raw per-run output (not tracked; see .gitignore)
```

`tables/` holds the per-seed JSON files from which the tables of the manuscript
are generated.

| File                               | Supports                                                  |
| ---------------------------------- | --------------------------------------------------------- |
| `coeff_traj_seed1.json`            | the source run's coefficient trajectory                   |
| `imagenet_frozen_fact_5seed.json`  | same-task transfer at source scale                        |
| `transfer_5seed_raw.json`          | the ViT, Swin and LinViT transfer tables, common config   |
| `transfer_5seed_stats.json`        | their paired, Holm-corrected tests                        |
| `linvit_tuned_5seed_raw.json`      | the LinViT target, activation-specific config             |
| `mixer_5seed_raw.json`             | the MLP-Mixer target, both configurations                  |
| `swin_depth_sweep_5seed_raw.json`  | the Swin depth sweep and the GELU-init control            |
| `vit_tuned_5seed_raw.json`         | the ViT target, activation-specific config                |
| `swin_tuned_5seed_raw.json`        | the Swin target, activation-specific config               |
| `vit_relearn_raw.json`             | the frozen curve against one learned in the target        |

Every file holds per-seed test top-1, over the five seeds the paper reports
except where noted. Coverage: both configurations, common and
activation-specific, for all four target architectures. In
`vit_relearn_raw.json` the frozen arm has six seeds and the target-trained arm
five, as in the manuscript.

The scripts that convert these files into LaTeX are distributed with the
manuscript rather than with this repository.

`logs/` is the destination of `scripts/train_targets.sh`. The raw logs and
checkpoints are deliberately untracked, since a run tree for the complete grid
comprises several thousand files. The tree may be regenerated by Path B of
[reproduction.md](../docs/reproduction.md), and the tables may be recomputed
from an existing tree:

```bash
scripts/evaluate.sh
```
